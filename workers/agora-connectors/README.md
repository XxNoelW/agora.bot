# Agora connectors proxy

This Worker is optional. The GitHub Pages site runs without it. Connectors marked **Needs the proxy** stay quiet until you paste the Worker URL into Connectors.

The Worker does two things:

- `POST /proxy` fetches a public HTTPS URL whose host is on the generated allowlist in `src/allow.js`.
- `POST /mcp` is a small Streamable HTTP MCP server for those same public fetches.
- `POST /mcp-proxy` forwards a Streamable HTTP call to an official MCP host that does not allow browser apps. A token you paste is sent only to that host. Deploy this Worker on your own Cloudflare account so the token does not pass through someone else’s server.

`src/allow.js` is generated by `node scripts/build-plugins.mjs`. Do not add an open proxy.

## Deploy

From the repo root, with a Cloudflare account:

```bash
cd workers/agora-connectors
npx wrangler login
npx wrangler deploy
```

Copy the `*.workers.dev` URL. In the site, open Connectors and paste it into **Proxy URL**. No token is stored in this repo.
